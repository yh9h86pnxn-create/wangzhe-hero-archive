## 🌟 项目亮点与核心特色（比官网更细节、更真实）

传统在线 MBTI 测评（如 16Personalities）常因**问题过于空泛抽象**（如“你经常陷入沉思”、“你喜欢参加派对”）、**混淆社交内向与认知内向**、以及**只给四个字母却缺乏深层认知功能解析**而饱受诟病。

本项目致力于打造一个**更加严谨、细节具体、真实生动且功能全面的全场景 MBTI 探索平台**：

### 🎯 1. 三大维度阶梯测评引擎（深度情景推演）
- **🌟 深度情景推演版（60题 · 强烈推荐）**：
  - 聚焦**真实职场分歧、高压截止日、旅行突发危机、亲密沟通需求、道德两难抉择**等具象微场景；
  - 摒弃模棱两可的抽象表述，每道题目包含真实场景还原（如“大场面社交能量断崖”、“思维闭门深思与即时大声讨论”）；
  - 采用 **7级 Likert 心理学量表**（极不符合 ~ 极符合），具备进度条平滑滑动、键盘导航、答题卡浮层及实时本地断点暂存（刷新不丢题）。
- **⚡ 快速高精准版（28题）**：精选区分度最高的 28 道高灵敏度核心探针题，3-5分钟快速定位。
- **🧠 荣格认知功能探索版（24题）**：专门探测 Ni / Ne / Si / Se / Ti / Te / Fi / Fe 认知八维栈的强弱与主从排序。

### 📊 2. 深度诊断看板与高清长图导出
- **精确百分比与微观倾向量表**：外向 E vs 内向 I、实感 S vs 直觉 N、思考 T vs 情感 F、判断 J vs 知觉 P 的精准能量百分比分布；
- **荣格八维架构拆解**：第一主导功能（Hero）、第二辅助功能（Parent）、第三缓解功能（Child）、第四劣势功能（Inferior）；
- **真实不粉饰的优缺点剖析**：三大核心降维优势 + 三大致命真实盲区；
- **高压黑化反噬（Grip Stress）自救指南**：解析当劣势功能失控时的异常表现与唤醒复原指南；
- **职场搞钱跑道与恋爱观特写**：最适环境、避坑雷区、容易被谁吸引、相处大忌；
- **🖼️ HTML5 Canvas 高清长图卡片一键生成与下载**：可生成 800×1100 像素的高清诊断卡片，支持长图下载与文本一键复制。

### 📖 3. 16型人格详尽档案大百科
- 涵盖 **NT 理性者**（INTJ、INTP、ENTJ、ENTP）、**NF 理想国**（INFJ、INFP、ENFJ、ENFP）、**SJ 守卫者**（ISTJ、ISFJ、ESTJ、ESFJ）、**SP 探险家**（ISTP、ISFP、ESTP、ESFP）四大气质家族；
- 支持实时模糊搜索（按字母、中文名、特质、名人）、气质家族一键过滤；
- 弹窗展开长篇深度专栏，包含**精神内核、图腾物象、认知栈、优缺点、黑化状态、职场搞钱、恋爱相处及代表名人人格**。

## 🚀 部署至 GitHub Pages 分享给朋友

本项目为标准纯前端架构，支持直接部署至 GitHub Pages：
1. 在 GitHub 上新建公开仓库（如 `mbti-universe`）；
2. 提交并推送到仓库：
   ```bash
   git add .
   git commit -m "feat: complete detailed MBTI platform with test, matrix and generator"
   git push -u origin mbti
   ```
3. 在 GitHub 仓库页面打开 **Settings** -> **Pages**；
4. **Branch** 选择当前分支，目录选择 `/ (root)`，点击 **Save**；
5. 稍等一至两分钟，即可通过公开链接分享给微信好友或发到朋友圈在线使用！
