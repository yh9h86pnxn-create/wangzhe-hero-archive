# ⚔️ 王者荣耀 · 英雄殿堂与全景战术实验室

---

## 🌟 项目亮点与核心功能

本项目以流行 MOBA 手游《王者荣耀》为内核，深度融合心理学价值观推演与竞技战术决策，提供一个**视觉殿堂级、功能细致入微、无须任何环境依赖、开箱即用的纯前端单页 Web 应用**。

---

### 🎯 1. 测算你的峡谷本命英雄（Soulmate Hero Diagnostic）
- **16道深度人格与价值观推演试题**：
  - 聚焦面对逆境绝境时的心境（逆风翻盘还是孤注一掷？）、人际信条（独行侠还是团队后盾？）、行事作风（稳健缜密还是狂放不羁？）与恩怨断舍；
  - 结合王者大陆六大精神哲学内核（孤勇信条、狂放不羁、权谋守护、超脱逍遥、热忱奉献、破晓无畏）；
- **全方位授勋看板**：
  - 测出最契合你的本命英雄，并展示高达百分之九十多的灵魂契合度；
  - 解读你的精神共鸣心法、代表台词箴言、英雄全技能机制与英雄传记；
  - 智能推荐与你最来电的**黄金搭档**以及需要警惕的**宿命天敌**；
- **🖼️ HTML5 Canvas 殿堂级授勋卡片生成**：
  - 一键渲染高清荣誉战卡（含个人契合度、专属称号、心境箴言及英雄印记）；
  - 支持**一键下载高清卡片**与**一键复制微信/朋友圈分享文案**。

## 🌐 上传 GitHub 并开启 GitHub Pages 分享给他人

想要把这个网站发布到公网，生成一个让所有人都可以用手机、微信、电脑随时打开的网址，只需按照以下步骤操作：

### 步骤 1：在 GitHub 上新建一个仓库
1. 打开并登录 [GitHub.com](https://github.com)；
2. 点击右上角的 `+` 按钮，选择 **New repository**；
3. 填写仓库名称，例如：`wangzhe-hero-archive` 或 `wangzhe-codex`；
4. 选择 **Public**（公开）；
5. **不要勾选** "Add a README file"（保持仓库为空）；
6. 点击绿色的 **Create repository** 按钮。

### 步骤 2：在终端将代码推送到你的 GitHub 仓库
在本地项目目录中打开 PowerShell 或终端，执行以下命令（将命令中的 `YOUR_USERNAME` 和 `YOUR_REPO` 替换为你实际的 GitHub 用户名与仓库名）：

```bash
# 1. 确保在 wangzhe 分支
git checkout wangzhe

# 2. 添加你新建的 GitHub 远程仓库
git remote add wangzhe-origin https://github.com/YOUR_USERNAME/wangzhe-hero-archive.git

# 3. 将代码推送到 GitHub 的 main 分支
git push -u wangzhe-origin wangzhe:main
```

### 步骤 3：开启 GitHub Pages 网站
1. 进入你在 GitHub 上的该仓库页面；
2. 点击页面上方的 **Settings**（设置）；
3. 在左侧菜单栏中点击 **Pages**；
4. 在 **Build and deployment** 下方的 **Branch** 下拉菜单中：
   - 选择 `main` 分支；
   - 目录选择 `/ (root)`；
   - 点击 **Save**（保存）；
5. 等待 1~2 分钟，刷新该页面，顶部就会出现绿色提示：
   > **Your site is live at `https://YOUR_USERNAME.github.io/wangzhe-hero-archive/`**
6. 点击该链接，或者直接将这个网址复制发送给微信好友、朋友圈、游戏队友，手机和电脑均可秒开使用！
