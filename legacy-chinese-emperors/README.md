## 🏛️ 项目概览
本网站是一个高雅古典的中国古代历史资料库与朝代纪年演进交互系统。全面系统地收录自秦始皇至清宣统两千余年大一统与分裂割据主要王朝的核心主流帝王档案，图文考据传世高清御容肖像、详尽生平功过、名言典故与后世史评；同时开辟自上而下的金色历史长河时间轴，清楚罗列各个朝代的时间节点、存续时长、建都地点以及著名的历史重大转折战役与政治制度改革变法。

## ✨ 核心特性与模块介绍

### 👑 1. 帝王画卷 · 历代名鉴资料库
- **权威高清传世御容**：严格考据故宫南熏殿藏历代帝王画像、阎立本《历代帝王图》、明清宫廷彩绘衮服御容肖像，并配备智能优雅的降级防裂图印章头像保障。
- **全系谱多朝代精准分类**：横向一键快速切换（秦代、西汉、东汉、三国、两晋、南北朝、盛唐武周、五代十国、北宋、南宋、辽金西夏、大元、大明王朝、大清帝国）。
- **特色印章特征多维过滤**：支持按“千古一帝”、“开国之君”、“盛世明君/中兴”、“变法改制”、“大一统”、“悲剧/亡国之君”分类。
- **全局实时模糊搜索**：支持帝王姓名（如“嬴政”、“李世民”）、庙号（“太祖”、“太宗”）、年号（“贞观”、“康熙”、“洪武”）、名言典故模糊查询。
- **天子诏书·深度档案模态弹窗（Modal）**：
  - 庙号、谥号、姓名、年号、在位年代、生卒寿考；
  - 平生概览速写；
  - 千秋功绩与治世政绩逐条清单；
  - 历史争议与历史教训；
  - 著名名言与传世名篇摘录；
  - 历史典故与著名轶事（如“指鹿为马”、“杯酒释兵权”、“成化犁庭”等）；
  - 后世名家客观评述（司马迁、资治通鉴、班固、王夫之等论定）；
  - 底部支持键盘左右方向键与【上一位/下一位】帝王丝滑快速翻阅。

### 📜 2. 华夏纪年 · 朝代演进大系（自上而下时间长河）

## 🚀 GitHub Pages 上传与分享部署说明
本项目已准备好直接部署至 GitHub Pages：
1. 在 GitHub 上创建一个名为 `chinese-emperors-archive` 的公开公开仓库（Public）；
2. 将本地代码推送到远程仓库：
   ```bash
   git remote set-url origin https://github.com/yh9h86pnxn-create/chinese-emperors-archive.git
   git push -u origin main
   ```
3. 打开 GitHub 仓库页面，点击 **Settings** -> **Pages**；
4. 在 **Build and deployment** 下的 **Branch** 选择 `main` 分支，目录选择 `/ (root)`，点击 **Save**；
5. 稍等一至两分钟，即可通过公开链接：
   `https://yh9h86pnxn-create.github.io/chinese-emperors-archive/`
   直接分享给他人点开使用！
